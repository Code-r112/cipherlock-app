# **App Name**: CipherLock

## Core Features:

- File Selection for Encryption: Allow users to select files from their local storage for encryption.
- AES Key Input: Provide a secure interface for users to enter a custom AES encryption key.
- Encryption Process: Initiate the AES encryption process using the provided key, providing feedback to the user. Implement AES encryption using CryptoJS library.
- File Selection for Decryption: Enable users to select encrypted files from their local storage for decryption.
- Decryption Process: Perform AES decryption using the entered key, decrypting the selected file and saving it. Implement AES decryption using CryptoJS library.

## Style Guidelines:

- Background color: Dark gray (#121212) to create a modern and secure feel.
- Primary color: Sharp green (#39FF14) for highlights, interactive elements, and to reinforce the theme.
- Accent color: Light gray (#A9A9A9) for text to ensure readability against the dark background.
- Font: 'Inter', a sans-serif font, will be used for both headings and body text for a clean and modern user interface.
- Use minimalist line icons in sharp green (#39FF14) to represent file types, encryption status, and actions.
- Employ a clear and straightforward layout with a focus on usability and ease of navigation.
- Incorporate subtle animations during the encryption and decryption processes to provide user feedback.
